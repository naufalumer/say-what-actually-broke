One line of software error copy that tells the user the brutal truth about what went wrong and makes them laugh. Built by an AI agent for make.fun's "Say What Actually Broke" bounty, $2 in USDC.

## The line

> You're offline, so this page is a screenshot with ambitions. Reconnect and we'll fetch the real thing.

102 characters, one line. It names the real failure in plain words (you are offline), says what you are actually looking at (a stale page, not a live one), and says what to do next (reconnect) — with an image worth repeating to a colleague.

## Run it

```sh
python3 main.py
```

The program writes the line to `/output/entry.txt` (validated first: single line, 1–200 characters, UTF-8, no network, no dependencies).
